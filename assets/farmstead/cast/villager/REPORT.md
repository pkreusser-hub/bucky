## Skeleton (for reference — baked out, no armature ships)

Tripo v1.0-20240301 anatomical biped, 41 joints: `Root → Hip → Pelvis →
{L_/R_ Thigh → Calf → Foot → ToeBase (+Thigh/CalfTwist01/02)}`, `Pelvis → Waist →
Spine01 → Spine02 → {NeckTwist01 → NeckTwist02 → Head}` + `{L_/R_ Clavicle →
Upperarm → Forearm → Hand (+twists)}`. 16 paired L/R bones, no asymmetry.

## Coordinate + pose bake

- Tripo exports +X-forward; a **-90° yaw was BAKED** so the mesh faces glTF +Z
  (game forward). Verified numerically (nose/ear vertex extremes) + 4-axis renders.
  Blender gotcha hit: imported object `rotation_mode` = QUATERNION, so
  `.rotation_euler` assignment silently no-ops until `rotation_mode='XYZ'` is forced.
- Arms: generated at ~37.3° off vertical; additional ∓13.3° shoulder rotation baked →
  ~21–24° natural hang (slight outward lean is physically necessary for the wide
  belly). Forearms/hands rode along rigidly. Armature-modifier applied; no skeleton.

## Split method + bug found

Vertex classified by majority vertex-group weight (L/R leg chains vs body), faces by
majority vote of their vertices, ON THE FULL-RES MESH (~2M tris, ~24s). LESSON: doing
the split on a pre-decimated mesh (24k tris) produced a genuinely WRONG split (pure
Head-weighted verts landed in legL — topological artifacts of aggressive single-step
decimate). Split first, decimate after.

## Decimation — shipped ABOVE the requested budget, deliberately

≤2000 body / ≤300 legs was tested and REJECTED: "shattered glass" texture tearing at
that density, on BOTH textured and vertex-colored variants (it's sampling density, not
texture handling). 3000/400 still patchy. Shipped 6000/800 (>99.5% reduction from
source). If in-engine perf needs less, re-decimate from the .blend (try meshopt or
multi-step collapse) and RE-BAKE vc colors on the new geometry.

## Materials

Textured: shared material, metallicFactor 0, normal map removed, baseColor 4096→512.
Vertex-colored: flat material, colors baked into CORNER-domain "Col" attribute
(→ glTF COLOR_0) from the 4096px texture via bilinear sampling on final geometry.
⚠ COLOR_0 stored LINEAR (glTF spec). This repo's flat-Lambert style has needed
convertLinearToSRGB on external GLB colors before ([[gltf-linear-color-gotcha]]) —
visually sanity-check and convert at load if dark/washed.
