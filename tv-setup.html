Bucky TV setup

Puts the Bucky home screen on the living room TV. Takes about 10 minutes with the TV remote. Part 2 needs a computer for one command.

Part 1: Install the app

  1. On the TV, open Settings → System → About. Scroll to Android TV OS build and click it 7 times, until it says you are a developer.
  2. Open the Google Play Store on the TV, search for Downloader (by AFTVnews) and install it.
  3. Go to Settings → Apps → Security & restrictions → Unknown sources and switch it on for Downloader.
  4. Open Downloader and type this address:
    amenfarms.netlify.app/tvapp/bucky-tv.apk
  5. When it asks, choose Install. If Google Play Protect warns that it doesn't know the app, choose Install anyway. It's ours, it just isn't in the Play Store.
  6. Bucky TV now shows in the TV's app list. Open it to check it works.

Part 2: Make it the home screen

This switches off Google's home screen, so the Home button opens Bucky instead. Nothing is deleted, and it can be switched back (see Part 3).

  1. On the TV, go to Settings → System → Developer options and turn on USB debugging.
  2. Find the TV's address in Settings → Network & Internet, under your Wi-Fi network. It looks like 192.168.1.42.
  3. On a computer on the same Wi-Fi, install Google's Android platform tools and open a terminal in that folder.
  4. Run these, using the TV's address. The TV will ask whether to allow debugging: choose Always allow and OK. 
    adb connect 192.168.1.42:5555
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
  5. Press Home on the remote. If the TV asks which home app to use, pick Bucky TV and Always.
  6. Turn USB debugging back off.
If adb connect is refused, look in Developer options for Wireless debugging. Turn it on, choose Pair device with pairing code, and run adb pair with the address and code it shows. Then run adb connect with the address it lists under Wireless debugging.
A Google TV system update can switch Google's home screen back on. If Home starts showing Google's screen again, repeat Part 2.

Part 3: Putting Google's home screen back

Repeat Part 2, but run this instead of the disable-user line:

adb shell pm enable com.google.android.apps.tv.launcherx

A factory reset also brings it back.

Using it

  1. The arrow buttons move between tiles, and the center button opens one.
  2. Apps (scroll down) has every other app on the TV, and TV settings at the end. Google's home screen is switched off, so the TV's settings are reached from here.
  3. After 5 minutes without a button press it shows goat photos with the clock. Any button brings the home screen back.
  4. Everything on the screen comes from the website, so changes to Bucky show up on the TV without reinstalling anything. The TV checks for a new version every 10 minutes and switches over the next time the goat photos come on, so it never changes while someone is using it.
